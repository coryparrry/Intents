# Owned simulator runner disposal

`intents-owned-disposal-3` is a narrow lifecycle patch to the published MIT-licensed `agent-device` 0.21.20 artifact. It changes the existing `runner-disposal.js` owner-lock seam the terminal `session2.js` close retention choice and the existing `runner-client.js` draining retry guard; it does not introduce another runner, daemon or device stack. `dependencies.lock.json` records the exact original, patched and helper hashes. The installer rejects unknown artifacts and mismatched reviewed hashes before writing, and every private build/staging path reapplies the same patch after npm installation.

The original disposal ignored simulator termination results and deleted its runner lease even when cleanup failed. The patched simulator path freshly matches the current lease's device, owner PID/start, session, runner PID/start, port and artifact paths before each operation. It terminates and uninstalls only the two default SDK runner bundles on that simulator. Runner-ID overrides are refused; the subject bundle and simulator boot state are preserved. Installed-app and loaded-job readback must establish absence before the SDK removes the lease. ASCII plist output uses the SDK's existing bounded `plutil` path. Failures preserve the lease and remain unresolved.

This receipt binds the SDK's host runner and session; it does not claim a kernel PID/start identity for the UIKit application inside the simulator. Native Intents independently verifies that no SDK UIKit runner job remains before releasing its target lease. Physical-device and native-Mac arrangements are unchanged and unqualified.

Verification: ten isolated Node lifecycle regressions and seven Python installer regressions pass. The snapshot-only engineering check did not start the touch runner and does not qualify its disposal. Production mixed attempt a1 created the fixture, then correctly withheld the Apple hand-off when SDK close retained/detached the touch runner. Its unresolved report remains unchanged; the owned simulator was shut down and exact runners exited. Patch3 disables retention at terminal simulator session close and re-enters strict disposal on draining retries, so a failed disposal cannot fall through to lease deletion. Production mixed attempts a7 and a8 created distinct fresh fixtures, released UI control, executed the real Apple intent and independently read the fixture/query from complete raw snapshots. Native job inventories showed no SDK runner jobs; both screenshots were viewed and the owned simulator was shut down. Qualification is limited to the exact simulator/build/runtime entries in `Verification/Automation/qualification-matrix.json`. No broad compatibility, physical-device, native-Mac or notarized-release claim follows from these checks.
