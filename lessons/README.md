# Versioned incident lessons

Write `lessons/<incident-id>.md` for a real incident, using `docs/sdlc/templates/incident.md`. Link the source alert/ticket/channel, detector evidence, attributable actions, authorization, recovery confirmation, follow-up intent, fix PR, and permanent eval. Distinguish cause from hypothesis.

Update runbooks and relevant recurring-error guidance with the fix. A resolved incident without a follow-up/eval decision leaves the playbook's loop open. Keep sensitive evidence in the approved incident system and link it instead of committing raw data. Do not create fictional lessons to fill this directory.
