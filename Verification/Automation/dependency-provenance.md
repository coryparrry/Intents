The new offline builder validator checks exact direct pins, both lockfiles, reviewed metadata hashes/repository identity, honest revision disposition, installed module/exports metadata, all recorded declarations and required public entry points. Optional archive mode verifies actual archive SHA512/SHA256 and bounded declaration inventory from the same hashed bytes. Packaging validates before staging and after npm ci, ships reviewed metadata snapshots, then signs/manifests the actual patched runtime. Default package checks explicitly do not reread upstream archive bytes or infer a commit.
