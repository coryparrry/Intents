# Private Mac ownership source extension

The product's native Mac execution route remains unavailable. This is a source experiment against the officially acquired agent-device revision `35f407e6e9352544847732d3b8aa74b7b3d34d51`, separate from installed SDK and signed package15.

`stage_mac_snapshot_ownership.py` creates a new private source tree after checking the published helper baselines before and after copying. Default mode adds exact-instance snapshots. `--application-ownership` adds exact-path open and identity commands. `--recipient-input` additionally replaces mouse press with recipient-scoped submission and requires identity on snapshots; it requires application ownership. No mode installs or enables the customer runtime. The stager attests its guarded files and patches; the separately hashed official archive establishes the upstream acquisition.

Identity contains bundle ID, canonical selected `.app` path, PID and kernel process-start token. Exact-path launch disables running-app substitution and initial activation, verifies the returned instance, then activates that instance and rechecks it. Multiple matching instances fail. Identity lookup performs no launch or activation. Post-dispatch failures remain uncertain and cannot trigger fallback or automatic retry.

The mouse implementation validates a complete identity and application surface, bounds finite coordinates and schedule, creates down/up events before dispatch, and posts every event directly to the selected PID. It uses no global HID posting. Cancellation follows structured cleanup; a detected reused or absent process cannot receive cleanup. An unknown up submission is not retried. A successful response says `submittedUnconfirmed`; application handling requires separate observation. Public PID event posting does not atomically bind a process generation, so its remaining race and window/hit-test behavior need actual runtime qualification.

Checked source: six Python staging tests, 25 focused Swift tests, three release-pipeline tests and shell syntax passed. Swift command used private module caches, `--jobs 2`, and filters `MacOwnedMouseDeliveryTests|MacApplicationOwnershipTests|MacApplicationTargetTests|ScreenshotResponseTests`. Test launch, activation and event submission are injected; no real app or input operation ran. The tests include wrong app copy, duplicate instances, identity drift, incomplete/duplicate arguments, missing-target downgrade, cancellation during hold, reused PID, and unknown down/up outcomes. Fresh Sol reviews found a weak dispatcher assertion and an unknown-up retry; both were corrected and the latter independently rechecked.

Evidence root: `/private/tmp/intents-agent-device-native-ownership-source1`. Immutable [snapshot checkpoint](mac-snapshot-ownership-1.json) and [acquisition/input checkpoint](mac-application-ownership-2.json) preserve separate source states and failures. Initial recursive-copy test failure and global-cache-denied build remain in their original logs. Later changes do not rewrite earlier hashes.
