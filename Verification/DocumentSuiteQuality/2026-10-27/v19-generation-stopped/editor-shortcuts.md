Control-S saves the active document without changing its file name.

Control-Shift-S opens Save As for the active document.

Control-Z undoes the most recent edit.

Control-Y redoes an edit that was undone.

The editor autosaves every 60 seconds while the document has unsaved changes.

Autosave does not run for documents opened in read-only mode.

The recovery panel offers the most recent autosaved version after an unexpected exit.

Closing a document with unsaved changes prompts the user to save, discard, or cancel closing.

Find searches only the active document. Find in Folder searches all supported files in the chosen folder.

The line-number display can be toggled from the View menu.

The editor preserves UTF-8 encoding when saving a UTF-8 text file.

Tabs are displayed as four spaces by default; this setting changes display width without rewriting the file.
